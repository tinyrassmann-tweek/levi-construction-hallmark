# Levi Construction — website & client portal

Complete Hallmark-upgraded source for Levi Construction General Contractors, LLC.

**Builders of People, Places, and Things**

Live site: https://levi-construction.tiny-rassmann.chatgpt.site/

## Run locally

Requires Node.js 24. The local preview and tests need no dependency installation.

```sh
node scripts/assemble.mjs
node scripts/preview.mjs
```

Open http://localhost:4173. The preview uses a development-only identity and a local SQLite database. Never expose that development server as production.

```sh
node --test tests/api.test.mjs
node scripts/validate-artifact.mjs
```

## Included

- Responsive landing page with persisted consultation requests
- Project updates, milestones, photos, messages, change approvals, and concern resolution
- Service-dog notices on the website, in the portal, and in the printable contract draft
- Original logo with the full tagline, architectural concept images, and locally hosted fonts
- Server-side project permissions and optimistic concurrency checks
- Cloudflare Worker / D1 schema and Google Cloud Run / Firestore adapter
- Hallmark design records and nine backend tests

`src/` is editable source; `worker/` and `dist/` are generated by `scripts/assemble.mjs`.

## Deployment

See [the launch guide](README.html) and `google-cloud/deploy.sh`. The published site uses its existing hosting setup. Google Cloud deployment still requires the target project, credentials, Firestore database, service account, and secrets.

Configure ADMIN_EMAIL in the hosting runtime. Google Cloud also needs SESSION_SECRET and ADMIN_PASSWORD_HASH in Secret Manager. No secret values, client records, or preview databases are included here.

The contract is a draft requiring completion before signature. Images are labeled AI-generated architectural inspiration, not photographs of completed Levi work. Email and SMS alerts are not configured.
